# Malharia Princesa

Código da versão institucional, com HTML, CSS e JavaScript separados.

## Como usar

Extraia o ZIP mantendo as pastas e abra `index.html` no navegador. Não exige instalação ou compilação. Para hospedar, envie todo o conteúdo para um serviço de sites estáticos.

## Arquivos

- `index.html`: página inicial até “O que tecemos”, seguida do rodapé.
- `institucional.html`: conteúdo institucional e contato, acessível pelo menu.
- `css/site.css`: estilos gerais, responsividade e temas claro/escuro.
- `css/campaign-layout.css`: estilos da página inicial e do rodapé.
- `js/site.js`: menus, carrossel, idiomas e interações.
- `js/translations.js`: textos e traduções.
- `js/theme.js`: aplicação inicial do tema salvo.
- `assets/`: imagens, vídeo, logotipos e bandeiras.

Edite os arquivos da pasta `css` para alterar o visual. O formulário de contato usa o serviço externo FormSubmit e mantém o endereço configurado no projeto; requer internet. Os links externos também exigem conexão.
